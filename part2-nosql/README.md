# Phase 2: NoSQL Analysis with MongoDB

This part explores why we might use a NoSQL database like MongoDB for a product catalog that changes frequently.

### Files in this folder:
- **products_catalog.json**: A sample set of product data with nested reviews.
- **mongodb_operations.js**: The JavaScript commands for querying and analyzing MongoDB data.
- **nosql_analysis.md**: My report comparing MySQL and MongoDB for this use case.
