# Phase 1: Relational Database and ETL Pipeline

In this part, I focused on cleaning the "dirty" CSV files and loading them into a structured MySQL database.

### Files in this folder:
- **schema.sql**: The SQL script to create the 4 tables (`customers`, `products`, `orders`, `order_items`).
- **etl_pipeline.py**: The Python script I wrote to extract, clean, and load the data.
- **business_queries.sql**: SQL answers for the business questions (Purchase History, Sales Trends).
- **schema_documentation.md**: Full details about the database design and why it follows 3NF.
- **data_quality_report.txt**: A summary generated by the script showing how many records were cleaned.
