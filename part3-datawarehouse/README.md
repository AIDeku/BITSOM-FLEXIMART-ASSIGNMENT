# Phase 3: Data Warehouse and Sales Analytics

In the final part, I designed a Data Warehouse using a Star Schema to help FlexiMart analyze their historical sales patterns.

### Files in this folder:
- **warehouse_schema.sql**: The script to build the Fact and Dimension tables.
- **warehouse_data.sql**: A large set of sample records to test the analytical queries.
- **analytics_queries.sql**: Advanced SQL queries for drill-down analysis and customer segmentation.
- **star_schema_design.md**: Documentation on why I chose this design and how data flows through it.
